# 環城選戰 — 0.2

四名虛構候選人的事件棋盤桌遊。原作 Alpha 0.42 保持原樣。直接開啟 index.html，或以靜態伺服器提供此目錄。

## 規則
- 每邊 13 格，共 48 格的方形環道；1 名玩家與 3 名 AI。
- 資金、媒體、地方團體、口才、形象、知名度、支持度各自獨立。媒體、地方團體、口才、形象是判定能力（1–6）；其他數值下限 0。
- 全場準備期有人資金達 60 → 造勢期有人知名度達 60 → 衝刺期有人支持度達 110 → 決戰期。一次行動最多前進一階段，不回退。
- 募款格依序 12／6／3／2 格。支持得失倍率依序 1／1／1.7／2（四捨五入）。這些是新專案試玩參數，尚未校準勝率。
- 準備期 8 個招募格：三張不重複蓋牌翻一張，看完效果可聘用或放棄，每人最多一名。費用不足不能聘用。能力變化受上下限限制。已聘用者改為地方互動，其他階段不開放招募。
- 移動、判定各擲 d6；d6 + 對應能力 ≥ 目標為成功。
- 跨專長倍率 = 1 + 最高判定能力 − 應對能力。較弱能力有較低成功率，成功支持、資金、知名度報酬較高；能力訓練不放大。夏薇媒體募款成功資金 +8；地方募款成功率 17%，成功資金 +32。
- 每格都有免費選項；花費無論成敗都支付。知名度不自動轉為支持。
- 決戰期負面手段攻擊其他人中支持最高者，同分依出場順序。失敗扣自己的支持、形象，並增加對手支持。
- 決戰期有人抵達或跨過左下角「投票日」，啟動最後一輪。四人完成同輪後以支持度結算，同分並列。沒有固定輪數；經過起點不加分。

## 程式與測試
- js/data.js：角色、初始數值、門檻、四階段共 192 個事件版本、幕僚卡與 AI 權重。
- js/rules.js：移動、招募、應對、階段、最後一輪、結算。
- js/ui.js：棋盤、階段進度、七項數值、翻卡、人物表情。
- node tests/rules.cjs：192 事件、幕僚、反擊、四種終局位置、同分與 120 場完整模擬。
- node tests/browser.cjs：Playwright；1440／768／390／320px。NODE_PATH 指向 Playwright 目錄，SMOKE_BROWSER_CHANNEL 預設 msedge。
- SMOKE_SITE_URL=https://zziichen.github.io/candidate-boardwalk/ 可測正式站；SMOKE_SCREENSHOT_DIR 可保存畫面。
